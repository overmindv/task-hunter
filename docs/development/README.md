## Стек

| Компонент | Технология |
|---|---|
| **Язык** | Go (core) + Python (NLP/ML для классификатора) |
| **База данных** | PostgreSQL |
| **Библиотеки Go** | `go-jet` (генерация типизированных SQL-запросов), `goose` (миграции), `samber/lo` (коллекции), `slog` (логи), `gotd/td` (MTProto Telegram), `goquery` (HTML-парсинг), `robfig/cron/v3` (расписание) |
| **Конфиг** | `envconfig` |
| **Тестирование** | Golden files для парсинга и классификации

## Формат задачи

Каждая задача использует поля:
- **Название** — не больше 7 слов
- **Для чего** — 1 предложение
- **Подробное описание** — пункты, что сделать
- **Тесты** — unit / компонентные / интеграционные
- **Сторипоинты** — 1 / 2 / 3 / 5

## Условные обозначения

- `[STORY-N]` — ссылка на story
- `[TASK-M]` — ссылка на задачу
- `{D}` — пакет/директория в коде
